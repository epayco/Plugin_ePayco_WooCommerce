**The official Davipay plugin for WooCommerce allows seamless payment processing for your online store.**

== Description ==

The official Davipay plugin enables seamless payment processing for your online store, allowing customers to complete their purchases using their preferred payment methods.

Installation is **straightforward and requires no technical expertise**, so you can start selling immediately.

== Method Payments ==

Davipay accepts Visa, MasterCard, American Express, Diners Club, SEPA, PSE (Bank Transfer), Cash (Efecty, Gana, Punto Red, Red Servi, Su Red, Paga todo, Acertemos, Gana Gana, Su Chance, Jer, La Perla), Daviplata, PayPal, SafetyPay, Davipuntos, Puntos Colombia (Coming soon) and more directly on your store with the Davipay plugin for WooCommerce, allowing payments for mobile and desktop. Also, Davipay supports 3D-Secure v 2.2.

== Installation ==

= Automatic Installation =

Automatic installation is super easy because WordPress takes care of the file transfers for you, so you don't even need to leave your web browser. To automatically install the Davipay plugin for Woocommerce Stripe plugin, just log in to your WordPress dashboard, go to the Plugins menu, and click Add New.

In the search field, type "Davipay plugin for Woocommerce" and hit Search Plugins. Once you find our plugin, you can check out details like the version, rating, and description. The best part? You can install it with a simple click on "Install Now" and then "Activate".

= Manual Installation =

1. Download the [zip](https://github.com/davipay/Plugin_Davipay_WooCommerce?tab=readme-ov-file#requisitos) or from the [WordPress Module Directory](https://wordpress.org/plugins/davipay-gateway/).
2. Go to the "Plugins" module and click on "Upload Plugin".
3. Upload the file, install, and activate the plugin.

Done!

= Installing this plugin won't slow down your store at all! =

If everything went smoothly, you'll find it in your list of "Installed Plugins" in the WordPress dashboard. Just enable it and then move on to integrating and setting up your Davipay account.

= Davipay Integration =

Log in to the Davipay dashboard with your credentials.

Next, go to the settings module, click on configuration-customizations, and finally, select the "Secret Keys" category.

Approve your account to go to production and receive real payments.

= Configuration=

1. Log in to the Davipay dashboard with your credentials.
2. Go to **Settings > Customizations > Secret Keys**.
3. Enter the **P_CUST_ID_CLIENTE, P_KEY, PUBLIC_KEY, PRIVATE_KEY**.
4. Test the store with sandbox credentials.
5. Approve your account to receive real payments.
